# ⚡ FitLog — Train With Intent. Log Every Set.

FitLog is a dark themed gym companion designed to eliminate clutter and streamline your daily routine. Pick your lifts from a comprehensive workout library, log them into your daily plan, track your metrics, and watch your weekly work add up.

## 🚀 Key Features

- **The Library:** A modern, visual grid displaying detailed information for target performance lifts.
- **Dynamic Daily Planner:** Efficiently manage your active routine with an interactive, shared state dashboard layout.
- **Synced Stats Dashboard:** Live calculation updates for **Exercises**, **Minutes**, and **Calories** dynamically tracking whether you are viewing your active timeline or saved bookmarks.
- **Context-Driven Architecture:** Decoupled states using dual React Context Providers (`WorkoutContext` and `TabContext`) for absolute data synchronization and lag-free UI transitions.
- **Fully Responsive Matrix:** Crafted from scratch using a mobile-first philosophy that completely flips and adapts complex items on smaller viewports.

## 🛠️ technologies

- **Framework:** Next.js (App Router Architecture)
- **Styling UI:** Tailwind CSS & DaisyUI
- **Icons:** React Icons
- **State Controls:** Pure React Hooks (`useContext`, `useState`)
- **Notifications:** React Toastify
- **Data Source:** https://api.abcz.workers.dev/api/fitlog
